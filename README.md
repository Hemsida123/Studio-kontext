# Studio Kontext – filer för GitHub Pages

1. Ladda upp alla filer och hela mappen assets till roten i ditt repository.
2. index.html ska ligga direkt i roten, tillsammans med styles.css, script.js och undersidorna.
3. Välj Settings → Pages → Deploy from a branch → main → /(root).
4. Spara och vänta tills GitHub har publicerat sidan.

Alla bilder och typsnitt ligger i assets/. Ladda alltså upp hela paketet, inte endast index.html.

Sidan innehåller 13 projekt med egna undersidor, ett filtrerbart arkiv, studion, tjänster och kontakt. E-post- och telefonknappar öppnar besökarens vanliga program. Ingen byggprocess eller serverkod krävs.

Vid byte av domän: ersätt https://studio-kontext-arkitektur.carlzzon121.chatgpt.site i HTML-filerna, sitemap.xml och robots.txt med din slutliga webbadress. Detta gäller sidornas SEO-adresser. De vanliga sidlänkarna är relativa och fungerar direkt även under en GitHub-repositoryadress.

Information och bilder kommer från Studio Kontexts egen webbplats: https://www.studiokontext.com/. Bildkrediter finns på projektsidorna. Typsnittens och ikonernas licenser ligger i assets/.
